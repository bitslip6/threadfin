## Phase 0 contract memo

Accepted after scout reconnaissance, subject to the refinements below. Existing APIs, SQL journal format, simulation invariants, SQL::offsetExists cached length, and PHP 8.1 compatibility remain mandatory.

1. **Outcomes/errors/performance:** Preserve legacy sentinels/logs/errors. Internal failures are independent of public error arrays or numeric return values. Allocate detailed outcomes only for active transactions/new APIs/observation, no ordinary-path round trips/scanner/hash/timing/events. Safe new exceptions carry errno/SQLSTATE; callback throwable stays primary if rollback fails, with bounded separate cleanup diagnostics. No retries in v1.
2. **Transactions:** `transaction(callable): mixed`, outer ownership only on idle autocommit sessions, nested unique savepoints. Reject pre-existing/external transactions, autocommit=0, user transaction controls/session changes/DDL/CALL/unknown implicit-commit statements in helper scopes before execution. Conservative DML/read scanner runs ONLY in active helper scopes, including executable comments/multi-statements. Internal controls use replay-aware seam with private bypass. Guarantee limited to transactional tables and caller-trusted SQL (functions/triggers/nontransactional side effects are caller responsibility). No mode changes or DB close inside scopes. Simulation runs callback without inspection/controls. Inner rollback can recover locally; deadlock/lost connection/ambiguous controls invalidate all affected scopes. Streams left open at exit must close and fail scope before rollback. Ownership probe must support MySQL as well as MariaDB or fail explicitly without unsafe BEGIN: consider `SELECT @@autocommit` plus `SET TRANSACTION READ WRITE` (fails in an existing transaction without committing) rather than assuming MariaDB-only `@@in_transaction` exists everywhere. Worker must verify native behavior.
3. **Prepared:** `fetch_prepared(string,array): SQL`, `execute_prepared(string,array,int): int`, positional lists only. null/bool/int/finite float/UTF-8 text plus explicit `BinaryParameter` bytes with bounded send_long_data chunks; reject resource/unsupported inputs before prepare, validate native param count in real mode. No guessed binary. Simulation no statement calls. Metadata/new diagnostics never include values. Real prepared writes reject enabled legacy replay before execution; simulated writes allowed. Buffered reads may use store_result/bind_result and independent row copies (portable, opt-in buffering cost); statements always close. Read APIs caller-trusted read-only SQL, require actual rowsets.
4. **Streaming:** `stream(string, legacy template data=null)` and `stream_prepared(string,array=[])`: closeable separate `StreamingRows` single-pass iterator. Raw MYSQLI_USE_RESULT; prepared bind_result/fetch, never store_result/get_result. One stream owns connection, competing driver operations reject before I/O. DB close releases stream first. Exhaustion/cancel/failure release ownership idempotently. Rows independent, no Countable/seek/all conversion. Simulated empty stream has no resources. Document try/finally.
5. **Telemetry:** `observe(?callable,array=[]): DB`, default off. Immutable PHP8.1 event fields: version, operation/correlation id, kind, real/simulated, success/failure/start/complete/cancelled, monotonic duration and nullable first-row/rows/affected/errno/sqlstate, keyed template identifier. No SQL/values/raw errors/credentials. Per-observer random HMAC key (optional supplied key) only when enabled. Bounded sample rate/slow threshold; unselected operations avoid hashing/events. Observer exceptions swallowed into bounded safe counters. Recursive observer DB operations rejected before driver without poisoning original transaction. Explicit stream start/terminal lifecycle timing.
6. **Modules:** lazy require_once via selected entry points or explicit standalone includes: db_stream.php, db_telemetry.php, db_dump.php, db_verify.php. Core transactions/prepared remain in db.php. No framework/autoloader or wholesale adapter refactor.
7. **Resumable dumps:** explicit new API `dump_resumable(DB, plain seekable file sink, checkpoint store, options): DumpReport`. v1 single-column integer PRIMARY KEY only (including unsigned BIGINT as canonical decimal strings bound as strings; native numeric ordering). Reject composite/no-key/unsupported key types and nonplain sinks before output. Quiesced source acknowledgement required; no hidden global locks/sleeps. Quote identifiers, explicit ordered columns and type-aware literals. Versioned checkpoint: source/schema nonsecret identity, table/phase/key, output identity/position/prefix hash/options. Flush whole header/DDL/batch then atomic checkpoint rename; resume verify committed prefix, reject shorter/corrupt output, truncate excess. Whole-batch budgets, process-restart not power-loss durability. Additional unsupported column/schema types must be explicit and validated before output, not silently corrupted.
8. **Replay verification:** callable plus thin CLI, explicit version-1 JSON manifest with journal hash/exact byte cut, baseline dump hash, expected canonical schema/count/SHA256 rows, timezone/charset/collation/type policy, nonsecret source identity. Legacy complete session envelopes only; reject malformed/incomplete/unsupported packets. Native protocol, no SQL CLI/metacommands. Parser must handle supported quote/comment/session modes or explicitly reject unsupported constructs. Fresh separate disposable server mandatory for EACH attempt (not just another schema). Preferred concrete backend launches installed MariaDB binaries via proc_open argv, fresh private datadir/socket, networking and LOCAL INFILE off, restricted replay credentials, bounded resources/deadline and finally cleanup. This bounded sandbox lifecycle is delegated to the verifier component; parent retains oversight and owns the shared test source server. No arbitrary existing destination acceptance on mere user attestation. Source credentials read-only and never reported; offline expected manifest supported. Canonical checksums length-frame bytes/type tags/NULL with stable ordering; unsupported types fail explicitly. Reports contain counts/hashes/status/position, no rows/raw errors/secrets by default. No raw row diff mode needed in v1.

All new safety/correctness work is part of explicitly invoked new APIs, not enabled for existing callers. Baseline PHP-only and native ordinary-query benchmarks captured in evidence for later comparison. Every worker confirms concrete API/ownership with parent before mutation; all phases require parent disposition of fresh review.

Phase 1 concrete gate approved: `ExecutionFailure` safe errno/sqlstate/transactionInvalidated exception, private per-scope failure latches, `transaction_cleanup_errors()` bounded to last 16 safe failures. Conservative scoped verb allowlist SELECT/INSERT/UPDATE/DELETE/REPLACE/SHOW/DESCRIBE/EXPLAIN with proper quote/comment/multistatement validation. Same local validation applies during simulated helper callbacks (still no driver probes/controls). Caught transaction SQL-eligibility/lifecycle guard failures must not silently permit commit. Existing pure pre-execution template/bulk/insert builder validation remains repairable if caught before any DB operation; do not instrument all legacy builders. Uncaught callback throwables always roll back. EXPLAIN support is conservatively limited to EXPLAIN SELECT in v1; unsupported ANALYZE/extensions reject explicitly. Ownership probe must prove rejection without committing an external transaction. Dedicated transaction unit/native fixtures authorized; shared mysqli boundary only minimal canned outcomes/codes, never a fake transaction engine.
